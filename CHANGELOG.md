# Repository changelog

Chronological history of this monorepo across every plugin release. Each
heading is a per-plugin release tag -- there is no repository version number.

For what changed in a plugin you installed, read that plugin's own
`CHANGELOG.md`. This file additionally records repo-level work (CI, licensing,
release tooling) that belongs to no single plugin.

Generated by [git-cliff](https://git-cliff.org) from commit history.
